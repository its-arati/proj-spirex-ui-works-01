# Day 01 - Portfolio Card

This task is a portfolio card exercise built with HTML and CSS, with a small amount of JavaScript support available in the task folder if needed.

## How To Open

Open [index.html](index.html) directly in a browser, or launch it with VS Code Live Server from the `day01` folder.

## Task Structure

- `index.html` is the main page for the task
- `css/` contains the task-specific styles
- `js/` is available for any task-specific scripts
