# Day 02 - Resume Page

This task is a resume-style portfolio page built with HTML and CSS, with additional styling support from Tailwind CSS and Font Awesome icons.

## How To Open

Open [index.html](index.html) directly in a browser, or launch it with VS Code Live Server from the `day02` folder.

## Task Structure

- [index.html](index.html) is the main page for the resume layout
- [css/portfolio-card.css](css/portfolio-card.css) contains the main card styling
- [css/resume.css](css/resume.css) contains the resume-specific layout and typography styles
- [js/](js/) is available for any task-specific scripts
