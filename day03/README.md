# Day 03 - Responsive Navbar

This task is a responsive navigation layout built with HTML, CSS, and a small amount of JavaScript for the mobile menu behavior.

## How To Open

Open [index.html](index.html) directly in a browser, or launch it with VS Code Live Server from the `day03` folder.

## Task Structure

- [index.html](index.html) is the main page for the responsive navbar demo
- [css/](css/) contains the task-specific styles
- [js/](js/) contains the menu interaction script
- [profile.jpg](profile.jpg) is the avatar image used in the header
