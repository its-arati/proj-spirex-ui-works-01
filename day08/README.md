# Day 08 — BMI Calculator

A small front-end exercise: a BMI (Body Mass Index) calculator built with HTML, CSS and JavaScript.

## Description

Enter weight (in kilograms) and height (in centimeters) to calculate your BMI. The page displays:

- the numeric BMI score (one decimal place)
- the BMI category (Underweight / Normal / Overweight / Obese)
- a visual indicator that moves across a colored range bar representing the BMI bands
- a Reset button to clear inputs

## Files

- `index.html` — main page and markup
- `css/style.css` — styles and layout
- `js/script.js` — BMI calculation and UI logic

## How to run

Open the folder and load `index.html` in a browser, or use a VS Code Live Server extension:

1. Open the folder in VS Code.
2. Right-click `index.html` and choose "Open with Live Server" (if installed), or open the file directly in your browser.

## Notes

- Inputs expect weight in kilograms and height in centimeters.
- Invalid or empty inputs will trigger an alert prompting for valid values.
- The indicator is positioned using a percentage mapping across preset BMI ranges.
