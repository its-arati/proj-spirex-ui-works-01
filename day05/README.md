# Day 05 - Rock Paper Scissors Game

This task is a small browser-based Rock Paper Scissors game built with HTML, CSS, and JavaScript. Players choose a weapon, compare it with a computer choice, and see the result along with score updates.

## How To Open

Open [index.html](index.html) in a browser, or launch it with VS Code Live Server from the `day05` folder.

## Task Structure

- [index.html](index.html) — main game page
- [css/](css/) — styles for the game layout and UI
  - [game.css](css/game.css) — main game styling
- [js/](js/) — game logic
  - [script.js](js/script.js) — Rock Paper Scissors gameplay logic
- [Images/](Images/) — game asset images for rock, paper, and scissors

## Notes

- The game uses simple client-side JavaScript to handle player input and score tracking.
- You can customize the visuals or extend the logic further as a practice exercise.
