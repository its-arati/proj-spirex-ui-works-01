# Day 07 - Color Palette Generator

This task is a small color palette generator built with HTML, CSS, and JavaScript. The page lets you pick a base color and generate a set of palette cards from it.

## How To Open

Open [index.html](index.html) in a browser, or launch it with VS Code Live Server from the `day07` folder.

## Task Structure

- [index.html](index.html) - main generator page
- [Image.png](Image.png) - heading icon used in the page title
- [css/](css/) - page styling
  - [style.css](css/style.css) - layout, color picker, button, and palette card styles
- [js/](js/) - generator behavior
  - [script2.js](js/script2.js) - palette generation logic and card rendering

## Notes

- The page uses the native HTML color input for choosing the base color.
- Palette cards are generated in the browser and displayed below the action button.
