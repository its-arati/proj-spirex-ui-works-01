# proj-spirex-ui-works-01

This repository contains small front-end practice tasks built with HTML, CSS, and JavaScript. Each task lives in its own folder so it can be opened and worked on independently.

## Repository Purpose

The goal of this repo is to keep a collection of focused UI exercises and mini-projects in one place. The structure is intended to make it easy to:

- browse available tasks
- open a task directly in the browser
- keep task-specific assets next to the task page

## How To Access Tasks

Each task has its own folder. Open the task folder and load its `index.html` file in a browser, or use Live Server from VS Code if you prefer local development.
