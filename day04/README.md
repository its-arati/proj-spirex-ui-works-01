# Day 04 - Form & Page Styles

This task demonstrates building a simple multi-section page with form styles and supporting page layout styles using HTML and CSS. It includes a small JavaScript file for light interactivity.

## How To Open

Open [index.html](index.html) in a browser, or launch it with VS Code Live Server from the `day04` folder.

## Task Structure

- [index.html](index.html) — main page for the demo
- [css/](css/) — task-specific styles
  - [form.css](css/form.css) — styles for forms and inputs
  - [page.css](css/page.css) — layout and page-level styles
- [js/](js/) — interaction scripts
  - [script.js](js/script.js) — small behavior enhancements

## Notes

- The CSS files are scoped to this task and can be inspected or modified independently.
- Use the browser dev tools or Live Server for quick iteration.
